REEMPLAZO

¿Qué es reemplazar variables?

05 / 16

Reemplazar variables significa sustituir las letras (variables) por números específicos para calcular el valor numérico de una expresión algebraica.

$$\text{Si } x=3, \; y=2, \; z=-1$$ $$\text{Calcular: } 2x - y$$ $$2(3) - 2 = 6 - 2 = 4$$ Reemplazar x por 3 e y por 2, luego operar
1
Identificar las variables y sus valores asignados.
2
Sustituir cada variable por su valor numérico.
3
Calcular respetando el orden de las operaciones (potencias, multiplicaciones/divisiones, sumas/restas).
⚠️
Importante: Siempre respeta el orden de las operaciones (PEMDAS): Paréntesis, Exponentes, Multiplicación/División, Adición/Sustracción.

PROPIEDADES

Propiedades de Potencias

08 / 16

Las propiedades de las potencias nos permiten simplificar expresiones y operar con potencias de manera eficiente.

✖️ Multiplicación · misma base
$$a^m \cdot a^n = a^{m+n}$$
$2^3 \cdot 2^4 = 2^7 = 128$
➗ División · misma base
$$a^m \div a^n = a^{m-n} \quad (a \neq 0)$$
$5^7 \div 5^3 = 5^4 = 625$
🔁 Potencia de una potencia
$$(a^m)^n = a^{m \cdot n}$$
$(2^3)^2 = 2^6 = 64$
✖️ Multiplicación · mismo exponente
$$a^n \cdot b^n = (a \cdot b)^n$$
$3^2 \cdot 4^2 = 12^2 = 144$
➗ División · mismo exponente
$$a^n \div b^n = (a \div b)^n \quad (b \neq 0)$$
$6^3 \div 2^3 = 3^3 = 27$
➖ Exponente negativo
$$a^{-n} = \frac{1}{a^n} \quad (a \neq 0)$$
$2^{-3} = \frac{1}{8}$

Reemplazo con propiedades de potencias

12 / 16

Podemos combinar el reemplazo de variables con las propiedades de potencias para simplificar y calcular expresiones más complejas.

$$\text{Si } x=2, \; y=3, \; z=4$$ Aplicamos propiedades antes o después de reemplazar
📝 Ejemplo 1
$x^2 \cdot x^3$ con $x=2$
→ $2^2 \cdot 2^3$
→ $2^{2+3} = 2^5 =$ $32$
📝 Ejemplo 2
$\frac{y^5}{y^2}$ con $y=3$
→ $3^{5-2}$
→ $3^3 =$ $27$

$\left(\frac{x^3}{y^2}\right)^{-2}$ con $x=2, y=3$
→ $\left(\frac{2^3}{3^2}\right)^{-2}$
→ $\left(\frac{8}{9}\right)^{-2}$
→ $\left(\frac{9}{8}\right)^2 =$ $\frac{81}{64}$
